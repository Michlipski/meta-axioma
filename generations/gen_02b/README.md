# Generation 2b ($G_{2b}$): The Recursive Multi-Tier Axiomatic Compiler

Generation 2b ($G_{2b}$) builds upon the foundational successes of $G_{1b}$ (Model-Based Statecharts, Epistemic Isolation, Post-Emission Witness) and $G_2$ (Axiomatic Boundaries & Exception Enclaves) to establish the first **Multi-Tier Usability & Axiom Matrix**, governed by **Stateful Human Overrides**, **Dynamic Weighted Recursion**, and **Thermodynamic Capital Partitioning**.

## 1. Quick Start

### Run G2b Unit Tests:
```bash
PYTHONPATH=generations/gen_02b/src python3 -m unittest discover -v -s generations/gen_02b/tests
```

### Run Full Axioma Lexis G2b End-to-End Compilation:
```bash
PYTHONPATH=generations/gen_02b/src python3 -m unittest -v generations/gen_02b/tests/test_compile_lexis.py
```

### Run Emitted Application Tests:
```bash
python3 -m unittest discover -v -s apps/axioma_lexis/tests
```

### Launch Axioma Lexis G2b:
```bash
cd apps/axioma_lexis
python3 run.py
# Open http://localhost:8090
```

3. **Dynamic Weighted Recursion (`[L1-G2B-003]`):** Configurable recursion depth, worker type depth weighting (0.5x exploratory research, 1.0x synthesis, terminal sinks), boundary reflection opinion probes (`trace/telemetry/recursion_depth_opinions.jsonl`), and live Mermaid DAGs (`recursion_tree.md`).
4. **Thermodynamic Capital Partitioning (`[L1-G2B-004]`):** 40% of total tokens strictly reserved as Protected Capital for terminal verification sinks.
5. **Ambitious Discovery Protocol (`[L1-G2B-005]`):** Broad domain expansion before deliberate scope-cutting.
6. **Anti-Phantom Emission Gate (`[NEG-G1B-001]`):** Mandatory non-zero file emission and passing live runtime substrate tests.
